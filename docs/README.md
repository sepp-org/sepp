# sepp docs

The documentation site at [github pages](https://sepp-org.github.io/sepp/docs/), built with [Next.js](https://nextjs.org) and [Fumadocs](https://fumadocs.vercel.app).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Content lives under `content/docs/`.
