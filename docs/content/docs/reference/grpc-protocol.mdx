The protobuf definitions for sepp are hosted on [buf.build](https://buf.build/sepp-org/sepp-proto/docs/main%3Asepp.v1) which is based on the [sepp proto GitHub repository](https://github.com/sepp-org/proto). If you wish to contribute changes to the protocol, please open a pull request against the proto repository.

## Downloading the proto files using buf

Buf is a tool for managing protobuf files. It can be used to vendor the protocol files into your own project. To do this, you will need to install buf and then run the following command:

```bash
buf export buf.build/sepp-org/sepp-proto:main -o proto
```
